# SG 한국삼공 영업사원 작물보호제 학습 도우미

신입·저연차 영업사원이 현장에서 제품·병해충·잡초 정보를 즉시 확인하고 학습할 수 있는 사내 교육용 웹앱입니다.
외부 서버 없이 동작하는 **단일 HTML 파일**이며, 모든 데이터가 파일 안에 포함되어 있어 오프라인에서도 열립니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 🔍 검색진단 | 병해충·잡초 검색 (병해충 기준으로 작물·추천제품 정리) |
| 💬 Hi, SG | 대화형 상담 + **음성 질문 / 답변 읽어주기** |
| 📝 업무일지 | Hi,SG 질문·답변 **자동 기록**, 메모 추가, 전체 복사 |
| 🎯 역량퀴즈 | 실제 제품 데이터에서 **자동 출제**, 정답률 누적 |
| 🧴 제품정보 | 제품·혼용정보·희석배수표 + **희석 계산기**(ℓ/말) |
| 💊 제형 | 제형별 형태·특징 설명 |
| 📷 사진진단 | 준비 중 |

## 인증코드

첫 화면에서 인증코드를 입력해야 들어갈 수 있습니다.

- 기본 인증코드: `SG2026`
- 기본 관리자 비밀번호: `sgadmin!2026`

좌측 사이드바 하단 **⚙️ 관리자 설정**에서 관리자 비밀번호를 입력하면 인증코드를 변경할 수 있습니다.

> ⚠️ **보안 안내 (반드시 확인)**
> 이 앱은 서버 없는 정적 웹페이지라, **인증코드가 페이지 소스에 포함**되어 있습니다.
> 브라우저의 "페이지 소스 보기"로 코드를 확인할 수 있으므로, 외부인을 완전히 차단하는 보안장치가 아니라
> **"사내용이니 링크를 함부로 공유하지 말라"는 수준의 관문**으로만 사용하세요.
> 또한 관리자 설정으로 바꾼 코드는 **그 브라우저에만 저장**됩니다.
> 배포본 전체의 기본 코드를 바꾸려면 `app.js`의 `DEFAULT_CODE` 값을 수정한 뒤 다시 빌드·배포해야 합니다.

## 빌드

```bash
node build_v2.js
```

생성물:

- `docs/index.html` — GitHub Pages 배포본
- `SG_영업사원 작물보호제 학습 도우미.html` — 그룹웨어(다우오피스) 자료실 업로드용
- `artifact.html` — 로컬 확인용

## 로컬에서 확인

```bash
node server.js
```

브라우저에서 `http://localhost:8934/artifact.html` 접속.

## GitHub Pages 배포

저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`,
Branch를 `main` / 폴더를 `/docs` 로 지정하면 `docs/index.html` 이 사이트로 게시됩니다.

> ⚠️ **저장소 공개 범위 주의**
> GitHub Pages를 무료 요금제에서 쓰려면 저장소가 **Public**이어야 합니다.
> 이 앱에는 회사 제품 데이터·기술정보가 모두 포함되어 있으므로, Public 저장소로 올리면
> **사내 자료가 인터넷에 전면 공개**됩니다.
> 사내 전용으로 유지하려면 GitHub **Organization 유료 플랜(Private Pages)** 을 사용하거나,
> 기존 방식대로 그룹웨어 자료실 배포를 권장합니다.
